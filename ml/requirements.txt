# ML-only dependencies for the Resume-to-Job Match Scorer.
# Kept separate from backend/requirements.txt so the core API never
# depends on the ML stack (spec: isolated package, CPU-only).
# Pinned exactly: the committed match_scorer.joblib artifact must unpickle
# against the same library versions it was trained with.
#
# Embeddings run through onnxruntime against the committed ONNX export of
# all-MiniLM-L6-v2 (ml/artifacts/onnx/, produced by ml/export_onnx.py) with a
# lightweight `tokenizers` tokenizer. This replaces torch + sentence-transformers,
# which resident-loaded ~500MB+ and downloaded the model live from HuggingFace on
# first request — enough to OOM-kill Render's 512MB free tier mid-request.
# torch/transformers are needed only to regenerate the artifact (see export_onnx.py),
# never at inference, so they are deliberately absent here.
